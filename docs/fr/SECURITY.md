# Politique de sécurité

## Versions supportées
Seule la dernière version sur la branche principale est supportée.

## Signaler une vulnérabilité
Merci de signaler les problèmes de sécurité **en privé**.

- Email: mohammed-el-amine.djellal@epitech.eu
- Ou via un GitHub Security Advisory si activé

Nous répondrons aussi vite que possible et coordonnerons un correctif.
