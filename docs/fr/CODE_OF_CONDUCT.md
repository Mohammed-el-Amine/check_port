# Code de conduite

## Engagement
Nous nous engageons à offrir un environnement de contribution respectueux et sans harcèlement.

## Comportements attendus
- Respect et bienveillance
- Acceptation des critiques constructives
- Collaboration et entraide

## Comportements inacceptables
- Harcèlement, discrimination, attaques personnelles
- Trolling ou propos insultants
- Publication d’informations privées sans consentement

## Application
Les mainteneurs font respecter ces règles.

## Signalement
Merci de contacter le mainteneur en privé.
